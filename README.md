.NET Core Backend Sandbox & Web API Architecture

Repositorio enfocado al desarrollo de soluciones Backend profesionales utilizando el ecosistema de **.NET 8 / C#**, arquitectura de APIs RESTful y persistencia de datos relacionales con **Entity Framework Core**.

---

## 🛠️ Tecnologías y Herramientas Utilizadas

- **Lenguaje:** C# (.NET 8)
- **Framework:** ASP.NET Core Web API
- **ORM & Persistencia:** Entity Framework Core (EF Core) + SQLite
- **Herramientas de Validación:** Postman & Swagger
- **Control de Versiones:** Git & GitHub CLI
